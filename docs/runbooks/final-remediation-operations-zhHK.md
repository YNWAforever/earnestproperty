# 同事設定、追蹤連結及銷售報表操作指南

> 狀態（2026-09-28）：以下是新功能的操作方法。正式使用前，管理員須先完成資料庫遷移、公司 Inbox／Folder 設定、試點驗收，並由發佈人員依次開啟對應的介面開關；Haze 的真實接收能力仍未核實。開啟頁面、搜尋、儲存映射或預覽連結都不會送出訊息。

## 1. 設定同事接收

1. 到 `/admin/whatsapp-settings`，在「同事接收設定」選擇**在職同事**，核對姓名、工作電郵及分行。分行是本地資料，不等同供應商 Folder。
2. 在「連接 Inbox」選已由管理員核實的 **Folder 名稱**，搜尋並選擇該同事的**確切 Inbox 帳戶**。同名帳戶不可單靠顯示名稱判斷。如沒有 Folder，先由管理員在進階設定錄入已於 WOZTELL 確認的名稱及 ID。
3. 按「檢查連接」。只有所選公司 Channel、Folder 與帳戶均核實後，才按「儲存已核實映射」。更換同事、帳戶或 Folder 後要重新檢查；版本衝突時保留選項、重新載入並重查。儲存不會發訊息。
4. 在「通知方式」分別設定 Inbox 私有備註或同事 WhatsApp 的目的地，再到「核實與試送」查看「Inbox 分派」「Inbox 私有備註」「同事 WhatsApp」三項能力。三者不可互相當作已核實。
5. 真正試送前，先按試送預覽核對內容、測試對話與收件人同意，再執行對應方式的明確試送。供應商「接納」、簽署送達回執、同事確認收到及回覆是不同證據；結果未明時先查原請求，勿再送一次。Haze 未取得確切帳戶、Folder 權限及收件證據前，不可啟用其指定路線。

若同事不再接新工作，在該同事映射填寫原因並按「停用接單」；既有工作要另行檢查。

## 2. 建立批量追蹤連結

1. 到 `/admin/whatsapp-links`，選現時公開的租售樓盤。可選網站、28hse、YouTube 等多個來源，或貼上 CSV／TSV；表頭須依次為 `public_listing_no,deal_type,source,placement_url_or_id,staff_reference`。
2. 每行核對公開樓編、租／售、來源和投放 URL／ID。網站使用 `website:primary`。外部同事代碼只會匹配已核實、同來源的映射；沒有代碼的行使用總台。展開後最多 1,000 行。
3. 按「預覽核對」，逐行看建立／重用／阻止原因及路線。修正任何行都會使原預覽失效，須按「重新預覽修正」。可只選合資格行，但必須再作一次新預覽；排除行留在草稿。
4. 明確確認後才提交；系統每批最多 50 行。中斷或結果未明時用同一 Batch ID「繼續同一批次」查回，不要開始新批次重送。只複製或匯出已確認成功的連結；未知結果不可當失敗重試。

預覽不會建立追蹤連結，也不會發送 WhatsApp 訊息。網站覆蓋補建應先用缺漏清單核對，再小批提交。

## 3. 查看銷售及代理績效

1. 到 `/admin/analytics` 的績效區。管理員可看獲授權範圍；經理只可看其分行，代理不能讀取私人財務報表。
2. 按香港日期、分行、同事、來源、租／售及 30／90 日轉換觀察期篩選，然後按「套用篩選」。篩選無效時先修正，不應假設報表自動放寬範圍。
3. 用「新增與轉換」「回覆及跟進」「成交及佣金」及當前待辦查看指標。每張卡都要連同**樣本、分母、定義及暫定／未能計算狀態**閱讀。成交轉換按查詢建立日期分組；當前待辦按現時狀態計。
4. 「買賣成交額」「代理加權成交額」及「應收佣金」是不同數值；租賃月租不算買賣成交額。未知佣金保持未知，未歸因歷史成交另列，測試／垃圾／未知品質不冒充有效業績。
5. 按指標開啟所屬明細，逐項核對來源；「匯出本頁 CSV」只匯出目前頁及權限範圍的資料。管理員修正品質須選狀態並填原因；標記合資格客戶亦須提供來源證據。修正後重新核對總數與明細。

正式啟用及回退次序見 `final-remediation-rollout.md`；每項缺少的外部證據見 `../reports/2026-09-27-final-fixes-ledger.md`。
